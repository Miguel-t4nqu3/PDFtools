Objetivo del proyecto
PDF Tools fue desarrollado como una solución de escritorio para apoyar las actividades del proyecto del Ministerio de Trabajo gestionado por Indra Group.

La aplicación surge como una alternativa a herramientas en línea de edición y conversión de PDF, cuyo acceso se encuentra restringido por políticas de seguridad. El objetivo principal es permitir que los usuarios realicen operaciones sobre documentos PDF de forma local, segura y sin depender de servicios externos.

Todas las funcionalidades se ejecutan directamente en el equipo del usuario, garantizando la privacidad de la información y el cumplimiento de los lineamientos de seguridad del entorno corporativo.
